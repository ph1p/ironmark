# Development

This project uses [pnpm](https://pnpm.io/) for package management.

## Build from source

```bash
pnpm setup:wasm   # install the wasm32 target and wasm-bindgen-cli
pnpm build        # release WASM build
```

| Command           | Description            |
| ----------------- | ---------------------- |
| `pnpm setup:wasm` | Install prerequisites  |
| `pnpm build`      | Release WASM build     |
| `pnpm build:dev`  | Debug WASM build       |
| `pnpm test`       | Run Rust tests         |
| `pnpm check`      | Format and lint check  |
| `pnpm fmt`        | Format Rust and JS     |
| `pnpm clean`      | Remove build artifacts |
| `pnpm docs:dev`   | Run this site locally  |
| `pnpm docs:build` | Build this site        |

## Tests

```bash
cargo test --offline                 # spec + integration + doctests
cargo test --offline -- commonmark   # only the 652 CommonMark spec examples
cargo test --offline -- <name>       # one test by name
```

## Fuzzing

Fuzz targets live in `fuzz/` and use [cargo-fuzz](https://github.com/rust-fuzz/cargo-fuzz), which needs a nightly toolchain.

```bash
cargo install cargo-fuzz
node fuzz/seed.mjs                       # seed corpora from the CommonMark spec
cargo +nightly fuzz run -O render_html -- \
  -max_total_time=60 -max_len=4096 -dict=fuzz/markdown.dict
```

| Target             | Checks                                                        |
| ------------------ | ------------------------------------------------------------- |
| `render_html`      | No panics; with raw HTML disabled, no raw tags or unsafe URLs |
| `url_sanitize`     | Every link form strips `javascript:`, `vbscript:` and `data:` |
| `ast_roundtrip`    | `parse_markdown` then `render_markdown` does not panic        |
| `html_to_markdown` | HTML to Markdown, then Markdown to HTML, does not panic       |
| `render_ansi`      | Terminal renderer does not panic at any width                 |

The first input bytes pick the parse options, so every target also explores option combinations. Set `IRONMARK_FUZZ_ROUNDTRIP=1` to make `ast_roundtrip` also assert that `render_markdown` is idempotent. Crash inputs are written to `fuzz/artifacts/<target>/`; replay one with `cargo +nightly fuzz run <target> <file>`. CI runs each target for 30 seconds.

## Architecture

Parsing runs in two phases: block parsing, then inline parsing, then rendering.

| Path          | Contents                                                        |
| ------------- | --------------------------------------------------------------- |
| `src/block/`  | Line-by-line block parser, containers, leaf blocks, HTML blocks |
| `src/inline/` | Delimiter runs, links, autolinks, entities                      |
| `src/render/` | HTML renderer and heading slugs                                 |
| `src/ansi/`   | Terminal renderer                                               |
| `src/mdx/`    | MDX to JSX                                                      |
| `wasm/`       | wasm-bindgen bindings, JS entries, types and build tool plugins |
| `playground/` | The web playground                                              |
| `docs/`       | This site (Vocs)                                                |

## Troubleshooting

**`wasm32-unknown-unknown target not found`** or **`wasm-bindgen not found`**: run `pnpm setup:wasm` to install all prerequisites.
