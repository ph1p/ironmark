# MDX

ironmark compiles [MDX](https://mdxjs.com/), which is Markdown with JSX tags, expressions in braces and `import`/`export`, to JSX. It is off by default (`enableMdx` / `enable_mdx`) and needs no extra dependencies.

- To import `.md` or `.mdx` files in an app, add one of the [build tool plugins](/plugins).
- `mdxToJsx` itself returns a JavaScript module that still contains JSX, for your own JSX transform (esbuild, Babel, SWC, Oxc, TypeScript).

:::danger[MDX is code]
Expressions and components run with the page's privileges. Only compile MDX from trusted authors: `disableRawHtml` does not make compiled MDX safe.
:::

## Quick start

:::code-group

```ts [JavaScript]
import { mdxToJsx } from "ironmark";

const { esm, jsx, module } = mdxToJsx(`import { Chart } from './chart.js'
export const year = 2026

# Report {year}

<Chart data={[1, 2]} />`);
```

```rust [Rust]
use ironmark::{render_jsx, ParseOptions};

let out = render_jsx("import X from './x'\n\n# Hi {props.name}\n\n<X />", &ParseOptions::default()).unwrap();
// out.esm == "import X from './x'"
// out.jsx == "<>\n<h1>Hi {props.name}</h1>\n<X />\n</>"
let module = out.to_module(); // ESM + `export default function MDXContent(props) { … }`
```

:::

`render_jsx` / `mdxToJsx` turn on `enable_mdx` themselves. Every other option (tables, task lists, highlight, …) applies as usual.

## Plain Markdown to JSX

To turn a plain `.md` file into a component, compile it without MDX syntax: braces and `import` lines stay text, raw HTML is rewritten as JSX (`class` becomes `className`, void tags self-close) and HTML comments are dropped.

:::code-group

```ts [JavaScript]
mdxToJsx("# Price {per month}", { markdown: true }).jsx;
// "<>\n<h1>Price &#123;per month&#125;</h1>\n</>"

ironmark.parse(source).jsx({ markdown: true, components: true });
```

```rust [Rust]
use ironmark::{render_markdown_jsx, JsxOptions, ParseOptions};

let out = render_markdown_jsx("# Price {per month}", &ParseOptions::default(), &JsxOptions::default()).unwrap();
```

:::

Raw HTML must still nest: an unclosed `<div>` is a compile error, as in MDX.

## Output

| Field (JS) | Rust                     | Contents                                                                         |
| ---------- | ------------------------ | -------------------------------------------------------------------------------- |
| `esm`      | `esm`                    | Top-level `import`/`export` statements, in document order                        |
| `jsx`      | `jsx`                    | The document body as one JSX fragment (`<>…</>`)                                 |
| `module`   | `to_module()`            | `esm` plus `export default function MDXContent(props)`: import this              |
| —          | `elements`, `references` | Markdown tags routed through `_components`, and components used but not declared |

Markdown becomes plain JSX elements (`<h1>`, `<p>`, `<pre><code className="language-js">`). Code block content becomes a JS string, so braces and whitespace survive. Braces in text are escaped to `&#123;` / `&#125;`.
