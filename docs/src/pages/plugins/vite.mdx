# Vite

`ironmark/vite` works in Vite 5 or newer and in tools built on it: SvelteKit, Nuxt, Storybook, Vitest.

```js
// vite.config.js
import react from "@vitejs/plugin-react";
import ironmarkMdx from "ironmark/vite";

export default {
  plugins: [ironmarkMdx(), react()],
};
```

Put `ironmarkMdx()` before the framework plugin. It runs with `enforce: "pre"`, compiles `.mdx` to JSX and then transforms the JSX with the project's own Vite: Oxc in Vite 8, esbuild before.

## Preact

```js
import preact from "@preact/preset-vite";
import ironmarkMdx from "ironmark/vite";

export default {
  plugins: [ironmarkMdx({ jsxImportSource: "preact" }), preact()],
};
```

## Storybook

In `.storybook/main.ts`, add the plugin through `viteFinal`. Use `providerImportSource` so `MDXProvider` components from `@mdx-js/react` apply:

```ts
import ironmarkMdx from "ironmark/vite";

export default {
  async viteFinal(config) {
    config.plugins = [
      ironmarkMdx({ providerImportSource: "@mdx-js/react" }),
      ...(config.plugins ?? []),
    ];
    return config;
  },
};
```

See [options](/plugins#options) for everything the plugin accepts.
